# Assets Folder

Place your assets in this folder:

## Required Assets

1. **profile-photo.jpg** (400x400px minimum, square format)
   - Professional headshot for the hero section
   - Recommended format: JPG or WebP
   - Recommended size: <200KB

2. **resume.pdf**
   - Your current resume in PDF format
   - Recommended size: <2MB
   - Should be optimized for web viewing

3. **favicon.ico**
   - Site favicon (32x32px and 180x180px versions)
   - Can be generated from your profile photo

## Optional Assets

- Project screenshots (1200x800px recommended)
- OG image for social sharing (1200x630px)
- Additional images for projects

## Image Optimization

Before uploading:
1. Compress images using tools like TinyPNG or ImageOptim
2. Convert to WebP format for better performance
3. Ensure proper alt text is added in HTML

## Notes

- All image paths in `index.html` reference this folder
- Update paths if you use a different folder structure
- Keep file sizes small for better page load performance
