# Pranav Kalakota — Portfolio

An interactive 3D portfolio built with Three.js and Vite. Walk around a tennis court, find hidden keys, and explore different sections.

## Stack

- Three.js
- Vite
- Vanilla JS

## Running locally

```bash
npm install
npm run dev
```
